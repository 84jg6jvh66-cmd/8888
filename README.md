# US Stock Expectancy V4
Mobile-first Streamlit app for U.S. stock screening, historical setup backtesting, and expectancy analysis.

V4 adds an automatic NASDAQ/NYSE-oriented universe, configurable batch scanning, confirmed-pivot levels that reduce look-ahead bias, and a minimum backtest sample-size warning.

Run: `pip install -r requirements.txt` then `streamlit run app.py`.
Deploy `app.py` from GitHub with Streamlit Community Cloud.
